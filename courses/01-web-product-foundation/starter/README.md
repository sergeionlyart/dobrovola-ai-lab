# Стартовый комплект курса

Этот каталог содержит проектные настройки Codex для первого курса.

Bootstrap-агент копирует всё содержимое каталога в репозиторий разработки студента, включая скрытые директории:

```text
AGENTS.md
roles/
  leader.md
  executor.md
.codex/agents/
.agents/skills/
.gitignore
```

## Как работает выбор роли

Проектный `AGENTS.md` содержит обязательную маршрутизацию:

- команда `Ты руководитель` направляет агента к `roles/leader.md`;
- команда `Ты исполнитель` направляет агента к `roles/executor.md`.

Ролевые файлы являются каноническим описанием полномочий, рабочего процесса и формата отчёта. Конфигурации в `.codex/agents/` служат дополнительными техническими оболочками для тех же ролей.

## Основной рабочий паттерн

```text
Пользователь → milestone руководителю
Руководитель → крупные рабочие пакеты исполнителям
Исполнитель → автономная реализация и отчёт
Руководитель → проверка, доработка, интеграция и финальная приёмка
```

Актуальные skills:

- `.agents/skills/lead-milestone/` — руководство milestone до полного результата;
- `.agents/skills/execute-work-package/` — автономное выполнение крупного рабочего пакета;
- `.agents/skills/release-review/` — независимая проверка релиза.

Стартовый комплект пока намеренно не содержит каркас самого веб-приложения. До первого потока преподаватель должен выбрать и зафиксировать единый технологический профиль, а затем добавить сюда соответствующий scaffold или ссылку на него.

До этого момента starter подходит для проверки методики, ролей, skills и подготовки рабочей среды, но не для полностью автоматического создания готового сайта.

Не копируй каталог `.git` из публичного репозитория курса в проект студента.
