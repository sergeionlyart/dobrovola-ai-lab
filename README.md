## Русский

### Что это за репозиторий

Dobrovola AI Native Lab — публичная база учебных материалов, стартовых комплектов и рабочих процессов для курсов по LLM и агентским системам.

Здесь мы не учимся «правильно разговаривать с нейросетью» в отрыве от практики. Каждый модуль строится вокруг реального результата: сайта, CRM, аналитического инструмента, внутреннего сервиса или другого цифрового продукта.

Базовый цикл методики:

```text
Идея → Blueprint → Критерии приёмки → План в Linear
→ Работа AI-агента → GitHub → Проверка → Релиз
```

Человек сохраняет ответственность за цель, ограничения, проверку и принятие результата. AI-агенты помогают исследовать, проектировать, писать код, тестировать и готовить артефакты.

### Что хранится здесь

- общая методика Dobrovola AI Native Lab;
- материалы и программы курсов;
- стартовые настройки проектов;
- `AGENTS.md`, роли и skills для Codex;
- шаблоны blueprint, критериев приёмки и отчётов;
- промпты для руководителя, исполнителя и аудитора;
- примеры учебных артефактов.

### Первый курс

**[AI-native Web Product 01: от идеи до работающего сайта](courses/01-web-product-foundation/README.md)**

Формат первого модуля: три онлайн-занятия по 60 минут и по два часа самостоятельной лаборатории после каждого занятия. Итог — первый работающий веб-продукт и воспроизводимый процесс его дальнейшего развития с помощью ChatGPT, Codex, GitHub и Linear.

> Статус: публичная alpha-версия. Методические материалы готовы для обсуждения и пилота; технологический starter приложения будет зафиксирован отдельно перед первым потоком.

### Как использовать репозиторий

1. Откройте каталог выбранного курса.
2. Начните с файла `START_HERE.md`.
3. Передайте bootstrap-промпт своему Codex-агенту.
4. Выполняйте задания по порядку и сохраняйте доказательства результата.
5. Не копируйте секреты, токены и персональные данные в публичные репозитории.

До первого стабильного релиза ветка `main` считается рабочей версией материалов.

## English

### What this repository is

Dobrovola AI Native Lab is a public learning hub for courses on LLMs, coding agents, and AI-native product development.

The goal is not to study prompting in isolation. Each module is built around a real deliverable: a website, CRM, analytics tool, internal service, or another practical digital product.

The core workflow is:

```text
Idea → Blueprint → Acceptance criteria → Linear plan
→ AI-agent delivery → GitHub → Review → Release
```

The human remains responsible for goals, constraints, verification, and final acceptance. AI agents help research, design, implement, test, and document the work.

### What you will find here

- the Dobrovola AI Native Lab methodology;
- course programs and learning materials;
- project starter kits;
- Codex `AGENTS.md`, custom roles, and skills;
- blueprint, acceptance, and reporting templates;
- prompts for lead, builder, and reviewer workflows;
- examples of verifiable project artifacts.

### First course

**[AI-native Web Product 01: from idea to a working website](courses/01-web-product-foundation/README.md#english)**

The first module includes three 60-minute online sessions and two hours of guided independent lab work after each session. The outcome is a first working web product and a repeatable process for improving it with ChatGPT, Codex, GitHub, and Linear.

> Status: public alpha. The methodology package is ready for review and pilot use. The application technology starter will be frozen separately before the first cohort.

### About the author

**Sergey Avdeichyk / Dobrovola** is a Candidate of Technical Sciences, AI/ML engineer, and researcher. He builds LLM copilots, agentic systems, and applied AI products for LegalTech, education, analytics, CRM/ERP, and workflow automation.

The Dobrovola methodology combines learning with delivery: participants do not study an abstract AI course. They build a real product, document decisions, verify evidence, and learn to manage AI agents as part of a project team.

1. Open the directory of the course you are taking.
2. Start with `START_HERE.md`.
3. Give the bootstrap prompt to your Codex agent.
4. Complete the assignments in order and keep evidence of each result.
5. Never commit secrets, access tokens, or personal data to a public repository.

Until the first stable release, the `main` branch is the working version of the materials.
